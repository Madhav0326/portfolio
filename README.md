---

## 🌟 Highlights & Features

- **Interactive Skills Constellation Matrix**: Orbital radar visualization mapping core competencies (SQL, Power BI, Python, DAX, Tableau, Excel) to production project applications.
- **Analytics Lab**: An interactive telemetry playground demonstrating real-time KPI metrics, conversion funnels, daily call volumes, and retry distributions.
- **In-Depth Case Study Modals**: Structured breakdowns of production projects featuring problem statements, methodology, measurable outcomes, and actual SQL / DAX snippets.
- **Responsive Architecture**: Pixel-perfect layout with fluid mobile drawer navigation, accessible typography, and smooth micro-interactions powered by Framer Motion.
- **Resume Direct Download & Preview**: Integrated PDF viewer and 1-click download options for verified credentials.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18.17+ or 20.x
- npm, pnpm, or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Madhav0326/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
npm run build
npm run start
```
